# Forge Review

Collect reviews in WordPress and display review lists and summaries.

## Installation and use

1. Place the `forge-review` folder in `wp-content/plugins/`.
2. Activate Forge Review in the WordPress Plugins screen.

Use `[fr_review_form]` to add a submission form, `[fr_reviews]` to display reviews, and `[fr_review_summary]` to show a summary.
